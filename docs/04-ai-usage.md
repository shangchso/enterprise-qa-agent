# 04 AI 辅助使用说明

## 1. AI 使用范围

AI 助手主要承担：

- 需求拆解：将题目转化为验收点与目录结构。
- 代码生成：数据层、两个工具、决策模型、Agent 循环与 CLI。
- 测试与文档：单元测试、Trace 核对、文档撰写。
- 问题定位：分析冲突组装与追问检索中的缺陷。

## 2. 个人理解与确认

候选人确认并理解：

- ReAct 循环：模型选择动作 → 执行工具 → 观察 → 调整或结束。
- 冲突查证：同话题不同答案时列引用请求确认，不凭空选择。
- 有据回答：答案必须由引用原文支持。
- 资料缺口：检索不到时如实说明，不编造。

## 3. 开发中的关键修正

场景验证中发现并修正两个问题：

1. **冲突项组装报错**：最初从检索候选（不含原文）取 `text` 导致
   KeyError。修正为通过片段 ID 关联已读取原文获取 `text`。
2. **追问答案取错**：上下文兜底把同话题的无关片段也纳入，导致追问
   "审批"误答成 D04-F1。修正为：文本已命中时不再用上下文扩展，仅在
   文本无命中时才用话题兜底，修正后追问正确命中 D04-F2。

## 4. 验证结论

- 7 个单元测试全部通过。
- 7 份场景 Trace 均由真实运行生成，可复现。
- 所有命令可在项目根目录直接复制运行。
