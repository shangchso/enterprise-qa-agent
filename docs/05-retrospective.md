# 05 复盘与回顾

## 1. 最难的问题

最有挑战的是**文档冲突处理与追问的精确性**：

- 冲突要在读取原文后给出可核对的引用，又不能擅自选择答案；
- 追问既要借助上下文解析"这个操作"这类指代，又不能让上下文把无关片段
  误带进答案。

通过"先文本匹配、无命中再上下文兜底"的两段式检索，让答案始终由最相关
的原文片段支持。

## 2. 学习收获

- 理解 RAG 的关键不是能检索，而是**答案必须有原文依据、冲突必须查证**。
- 掌握用关键词与同义词设计可复现的离线检索。
- 体会引用（citation）与资料缺口对可信问答的重要性。
- 认识到"无依据回答或错误引用是关键缺陷"。

## 3. 不足与下一步

- 引入向量语义检索，提升复杂改写与长尾问题的召回。
- 实现冲突确认后的自动续答，形成完整闭环。
- 接入真实大模型，对比 Mock 与真实决策差异。
- 增加文档版本优先级与适用范围字段，支持自动消解部分冲突。
